## 🧪 Experiments / Labs

### Lab 1 – Software Requirements
Focused on identifying, documenting, and analyzing software requirements.

**Deliverables:**
- Functional Requirements (FR) & Non-Functional Requirements (NFR) table
- Use case flow documentation
- Use case diagram

**Key concepts:** Requirements elicitation, prioritization, acceptance criteria, and rationale.

### Lab 2 – Project Management with Jira
Hands-on experience with issue tracking and agile project management using Jira.

**Deliverable:**  
`PES1UG24CS184_SE_Jira.pdf` – Screenshots and documentation of Jira board setup, issues, workflows, and project tracking.

### Lab 3 – Software Design & Modeling
Creation of design artifacts using draw.io and written justification of design choices.

**Deliverables:**
- UML / design diagrams (`Lab 3.drawio-1.pdf`)
- Design justification document (`Lab3_Justification.docx`)

### Lab 4 – Arm Wrestle Showdown (AI-Assisted Development)
A Pygame-based arm-wrestling (tug-of-war) game used as a vehicle for debugging, feature implementation, and effective use of LLMs as pair-programming partners.

**Project highlights:**
- Vector-based arm positioning and stamina system
- Alternating key-press input mechanics
- Simple AI opponent with force application
- Deliberate bug + feature tasks completed with Claude (chat history included)

**Tasks completed:**
1. Fixed inverted arm-push direction bug
2. Implemented dynamic AI surge / difficulty spikes
3. Added visual exhaustion warning indicator

**How to run:**
```bash
pip install pygame
python main.py
```
**Controls:** Alternate ← → arrow keys rapidly | `R` to restart after a match
